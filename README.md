# SarayBelly 動画トリマー

PC内の動画から、30秒・60秒または自由な長さのクリップを切り出す無料の
ローカルツールです。プレビューを確認して、完成した動画をMP4で保存できます。
動画の処理はFFmpegでPC内で行い、有料APIやサブスクリプションは不要です。

## 必要なもの

- Python 3.10以降
- FFmpeg（PATHに登録）

Pythonの依存パッケージをインストールします。

```powershell
python -m pip install -r requirements.txt
```

## ウェブサイトを起動

```powershell
python app.py
```

ブラウザーで `http://127.0.0.1:5000` を開き、PCから動画を選択します。
切り出す長さと開始位置を指定し、「トリミングしてプレビュー」を選びます。
「保存先を選んでMP4を保存」からPC上の保存先を指定できます。
画面右上の言語メニューで日本語と英語を切り替えられます。

## デスクトップから起動

```powershell
python video_downloader.py
```

ローカルアプリを起動して、既定のブラウザーで開きます。使用中はターミナルを
開いたままにしてください。終了するにはターミナルで Ctrl+C を押します。

ローカルサーバーはこのPCからのみ接続できます。動画のアップロード上限は
4 GBです。FFmpegでH.264/AACのMP4に変換して書き出します。
